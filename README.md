# Lumen Agora｜开放学术公共广场

**一句话介绍：**  
Lumen Agora 是一个开源、非营利、公共性的研究交流平台，结合内容社区的轻量发现体验和职业网络的身份连接能力，帮助论文、研究想法、复现记录、问题讨论和学术机会被更好地发现、解释与连接。

## 产品定位

Lumen Agora 可以理解为面向学术和研究场景的“内容发现 + 学术网络”平台。

它借鉴小红书式的卡片浏览、轻量表达和碎片时间发现体验，也借鉴领英式的身份主页、履历展示、机构连接和机会发布机制。但 Lumen Agora 的目标不是复制任何现有平台，而是把这些产品能力改造成一个开源、非营利、可信治理的学术公共基础设施。

简单来说：

- 内容社区负责让研究被看见。
- 学术网络负责让研究者被连接。
- 开源公共治理负责让平台保持可信、开放和长期可持续。

## 灵感与问题

在小红书等内容平台上，已经有很多本科生、研究生、博士生和科研工作者在寻找机会、建立联系、分享研究经历，并提高自己工作的曝光度。但这些需求目前主要依赖通用内容平台的推荐机制，并没有被专门为学术场景设计。

在领英等职业网络上，用户可以展示身份、履历和机会，但学术论文、研究想法、复现记录和具体问题讨论并不是核心内容。很多学术交流仍然分散在期刊网站、arXiv、Google Scholar、Twitter/X、公众号、实验室主页和邮件列表中。

Lumen Agora 希望把这两类需求结合起来：一方面让作者可以把自己工作的重点、贡献和背景整理成易读的研究卡片；另一方面让学生、研究者、课题组和机构可以通过可信身份、主页和机会信息建立连接。

平台不会托管未经授权的论文全文，也不会直接搬运论文摘要。Lumen Agora 会展示 DOI、arXiv、出版商链接、代码和数据链接，并鼓励作者和读者发布原创导读、研究笔记、复现记录和问题讨论。

## 核心功能

- **研究信息卡片**：以轻量卡片形式展示研究工作的重点、贡献、关键词和适合读者，帮助用户快速发现新论文、新想法和新机会。
- **详细页面**：点击卡片后进入详细页面，展示标题、作者、原创导读、讨论区和原文出处。
- **原文出处**：展示 DOI、arXiv、期刊/会议页面、出版商链接、代码和数据链接，用户可以直接打开正式来源，避免版权风险。
- **点赞收藏**：点赞和收藏用于帮助用户标记有价值内容，但平台不会简单以热度作为学术价值判断标准。
- **评论讨论**：作者和读者可以围绕论文、方法、实验、复现结果和开放问题展开高质量讨论。
- **研究者主页**：研究者可以展示研究方向、论文、项目、经历、联系方式和开放合作意向。
- **学生主页**：学生可以展示简历、研究兴趣、项目经历、复现记录和希望申请或合作的方向。
- **课题组和机构主页**：导师、实验室、课题组和研究机构可以展示研究方向、成员、论文导读、项目和开放机会。
- **私信与合作连接**：用户可以基于感兴趣的论文、研究想法、复现记录或机会信息发起私聊，推动进一步交流、合作和新 idea 的产生。
- **机会连接**：认证用户可以发布或申请 RA、PhD、Postdoc、访问学生、实习、合作和开源研究项目等机会。

## 身份与治理

Lumen Agora 采用分层身份系统。普通用户也可以加入、浏览、收藏和参与讨论；通过学术邮箱、机构邮箱、ORCID、GitHub 等方式认证的用户可以获得更高权限，例如认领论文、发布作者导读、发布课题组招聘信息等。

用户发言时可以选择使用真实认证身份，或使用社区用户名参与普通讨论，以平衡可信度和表达自由。认证代表身份已验证，不代表观点一定正确；未认证代表身份未验证，不代表内容低质量。

平台将坚持开源、非营利和公共治理原则。代码、社区规则、治理原则和推荐机制的基本逻辑应尽可能透明，同时保留必要的反滥用和安全机制。公开内容应支持导出和开放 API；长期目标是让大学、图书馆、实验室和公益组织都能参与共建，而不是成为一个封闭商业平台。

## 冷启动与推广

Lumen Agora 的早期运营会从可信的学术圈层开始。第一批用户将优先邀请认识的学者、博士生、研究生、工程研究者和课题组，请他们先发布高质量的论文导读、研究卡片、复现记录和机会信息，形成第一批有价值的种子内容。

早期推广可以优先从计算机和机器人领域切入。这些领域研究更新快、新想法多、论文和代码传播频繁，也更接近开源文化，适合作为 Lumen Agora 的第一批核心社区。等产品机制、治理规则和内容质量稳定后，再逐步扩展到更多学科。

人群扩散上，可以先从中文学术圈和美国高校/研究机构网络双线推进。中国和美国都有庞大的学生、研究者、实验室和开源社区，如果两边能形成早期内容和讨论网络，后续再推广到其他国家、地区和学科会更加自然。

早期加入的研究者和课题组可以获得更早的曝光、影响力沉淀和社区参与位置。随着平台内容增长，未加入的机构和研究者也会看到额外的展示机会，从而形成主动加入的动力。

## 开源与公共性

Lumen Agora 希望成为面向全人类知识共同体的开放基础设施，而不是一个封闭商业平台。项目将尽可能坚持：

- 代码开源。
- 非营利导向。
- 公开透明的社区规则。
- 可解释的推荐和治理原则。
- 对用户数据和公开内容的可导出支持。
- 面向大学、图书馆、实验室和公益组织的开放 API。
- 长期探索自托管、多节点协作的可能性。

## 愿景

Lumen Agora 的愿景是：让论文不只是被发表，而是被看见、被解释、被讨论、被复现，并连接到新的研究机会。

它不是一个简单的“学术版小红书”，也不是一个普通的学术版领英，而是一个结合研究发现、学术讨论、身份连接和机会匹配的开放学术公共基础设施。

## 后续方向

1. 支持多语言内容和翻译，帮助不同国家和地区的研究者交流。
2. 继续研究版权、隐私、合规、身份认证和内容治理问题。
3. 从计算机和机器人领域开始，逐步扩展到更多学科。
4. 探索开放 API、数据导出、自托管和跨机构共建机制。
